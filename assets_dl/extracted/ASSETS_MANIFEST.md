# 捕鱼游戏美术 & 音效素材清单（AI-19 交付）

> 成品资源，严格对齐引擎资源契约，前端可原位替换占位资源，无需改动任何逻辑。
> 所有鱼/炮台/子弹一律「朝右侧视」，锚点为图形中心（引擎按 `facing` 自动翻转）。
> 每个图形同时提供 `.png`（引擎加载用）与 `.svg`（矢量源，可二次编辑）。

## 四、音效（44.1kHz / 16-bit / 单声道 WAV，接口 `play(name)`）

| name | 文件名 | 时长 | 描述 |
|---|---|:---:|---|
| `shoot` | `sfx_shoot.wav` | 0.10s | 开炮，清脆下滑「啾」+ 噪声爆点 |
| `hit` | `sfx_hit.wav` | 0.06s | 命中，短促「哒」高频点击 |
| `capture` | `sfx_capture.wav` | 0.22s | 捕获，C-E-G-C 上行琶音，奖励感 |
| `coin` | `sfx_coin.wav` | 0.15s | 金币入账，经典双音叮当 |
| `bgm_loop`（可选） | `bgm_loop.wav` | 8.0s | 海底氛围 BGM，Am-F-C-G，接缝淡入淡出可无缝循环 |

> 接入方式：把 `engine/sound.js` 的合成桩替换为按 `name → 文件` 映射的 `AudioBuffer` 播放，`play(name)` 接口不变，引擎零改动。`name ∈ shoot|hit|capture|coin`；BGM 单独循环播放。

## 五、接入备注
- 素材位于 `frontend/src/modules/fishing/assets/`，与引擎同模块。
- 鱼图中心锚点 + 朝右，直接对应 `_drawFish` 的翻转逻辑；无需额外偏移。
- 若只需 PNG，`.svg` 源文件可忽略（保留用于后续改色/改型）。
