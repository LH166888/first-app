# 平台外壳 + 模块 架构设计（Shell + Modules）

> 状态：待实施 ｜ 生成日期：2026-09-18 ｜ 首页风格：**A · 门户首页（Launchpad）**
> 平台名：**AI 无限** ｜ 适用项目：che-bang（Laravel 12 + Vue 3），部署 Render + Vercel

## 一、背景与问题

项目正从「纯车榜」演进为多功能应用，未来至少三个平级模块：**车榜**、**菜单**、**工具箱（身份证识别等）**。

当前架构的坏味道：**车榜「既是平台又是模块」**。

- `App.vue` 的全局顶栏 logo 是 🚗车榜，全局搜索框写死「搜索车型/品牌」——把某个模块的元素当成了全局元素。
- 车榜排行占据根路径 `/`，等于把「一个模块」当成了「整个应用首页」。
- 身份证识别被硬塞进车榜顶栏的「工具」下拉里，与车榜业务毫不相关。
- 菜单模块即将加入，若延续现状只能继续往车榜里塞，归属混乱。

根因：没有区分「平台外壳」与「业务模块」。

## 二、目标架构：三层

把应用分三层，车榜从「根」降级为「模块之一」：

**第 1 层 · 中性平台外壳**（改造后的 `App.vue`）
- 顶栏放**平台** logo「**AI 无限**」（不再是车），共享的登录/用户区。
- 根路径 `/` 是**门户首页（Launchpad）**：全屏海洋主题视频背景 + 毛玻璃画册轮播切换器，用户先选模块再进入。详见「八、门户首页视觉设计」。

**第 2 层 · 业务模块（各自子布局 + 独立路由命名空间）**
- `/cars`：车榜模块，**搜索框与车 logo 下沉到车榜自己的子头**。
- `/menu`：菜单模块，自己的子导航（我的菜单 / 创建 / 点单）。
- `/tools`：工具箱模块，身份证识别归此，后续新工具也在此。

**第 3 层 · 共享内核（跨模块复用）**
- 登录鉴权、用户 store、http client、R2 图片上传——所有模块共用一套。这是留在同一项目的最大红利，也是点单等跨用户功能的前提。

## 三、前端目录结构

```
src/
  App.vue                 ← 中性平台外壳(平台logo + 模块切换 + 用户区)
  router.js               ← 只负责汇总各模块 routes
  shared/                 ← 跨模块共享:store、api/client、AuthModal、R2上传
  components/             ← 真正通用的 UI 组件
  modules/
    home/  HomeView.vue   ← 门户首页(视频背景 + 毛玻璃画册轮播入口)
    car/
      routes.js
      CarLayout.vue       ← 车榜专属子头(搜索框在这)
      views/ components/ api/
    menu/
      routes.js
      MenuLayout.vue
      views/ components/ api/
    tools/
      routes.js
      views/ (IdCardView)
```

现有文件迁移映射（示意，非破坏性）：

| 现在 | 迁移到 |
|---|---|
| `views/RankingView / CarDetailView / CompareView / FavoritesView` | `modules/car/views/` |
| `components/CarRow / CarThumb / ChartCanvas / CompareBar` | `modules/car/components/` |
| `api/cars.js / favorites.js` | `modules/car/api/` |
| `views/IdCardView` + `api/idcard.js` | `modules/tools/` |
| `components/AuthModal / LoginToast`、`store.js`、`api/client.js`、`api/auth.js` | `shared/` |

## 四、路由设计（门户首页 + 嵌套布局）

根路径为门户首页；各模块用**嵌套布局**，层级归属一眼可辨：

```
/                → HomeView(门户首页:视频背景 + 毛玻璃画册轮播)
/cars            → CarLayout > 排行(RankingView)
/cars/:id        → CarLayout > 车型详情
/cars/compare    → CarLayout > 对比
/cars/favorites  → CarLayout > 收藏
/menu            → MenuLayout > 我的菜单
/menu/create     → MenuLayout > 创建菜单
/menu/:id        → MenuLayout > 菜单详情/点单
/orders          → MenuLayout > 点单明细(我收到的/我下的)
/tools           → ToolsLayout > 工具列表
/tools/idcard    → ToolsLayout > 身份证识别
```

`router.js` 由各模块 `routes.js` 拼装：

```js
import homeRoutes from './modules/home/routes'
import carRoutes from './modules/car/routes'
import menuRoutes from './modules/menu/routes'
import toolsRoutes from './modules/tools/routes'

const routes = [...homeRoutes, ...carRoutes, ...menuRoutes, ...toolsRoutes]
```

**兼容旧链接**：原 `/`（车榜）、`/car/:id`、`/compare`、`/favorites`、`/tools/idcard` 通过 `redirect` 指向新路径，已分享出去的链接不失效。登录守卫（`meta.requiresAuth`）逻辑保留不变。

## 五、后端目录与路由镜像

后端同样按模块分目录、路由按 prefix 分组，与前端镜像：

```
app/Http/Controllers/Api/
  Car/     (CarController, FavoriteController)
  Menu/    (MenuController, OrderController, IngredientController...)
  Tools/   (IdCardController)
  AuthController.php   ← 鉴权属共享,留在 Api 根或 Shared/
```

`routes/api.php`：

```php
Route::prefix('cars')->group(...);       // 车型/收藏
Route::prefix('menu')->middleware('auth:sanctum')->group(...);
Route::prefix('tools')->middleware('auth:sanctum')->group(...);
// 注册/登录/登出/user 仍为共享,保持现状
```

> 后端 Controller 移动目录会改 namespace，属公共文件改动，实施前单独确认。可与前端解耦，分批做。

## 七、已决策事项

（原待确认 5 项，已拍板如下）

1. **平台命名**：平台名定为「**AI 无限**」，顶栏与门户首页统一用此标识，替换原「车榜 ChéBǎng」。
2. **门户首页信息量**：首页不只是卡片墙，而是**视频背景 + 内容化推荐**——以菜单推荐为首屏展示内容，走高级质感路线（详见第八节）。
3. **模块切换器形态**：采用**毛玻璃画册式轮播**，默认自动轮转，点击卡片进入对应模块；非顶栏平铺 tab。
4. **旧路径处理**：**确认**车榜从 `/` 迁到 `/cars`，旧路径 `/`、`/car/:id`、`/compare`、`/favorites`、`/tools/idcard` 全部做 redirect，保链接与 Analytics 连续性。
5. **后端镜像时机**：**后做**——后端 Controller 分目录放到菜单上线之后，先不与前端骨架耦合，降低一次性风险（对应第六节第 3 步为可选）。

> 本设计涉及 `App.vue`、`router.js` 等公共文件重构，文档先行；实际改代码按上述步骤分批进行，每一步动公共文件前单独确认。

## 八、门户首页视觉设计（AI 无限 · Launchpad）

首页目标：一眼「高级」，弱化「工具站」感，用海洋光影 + 毛玻璃营造质感，把模块入口做成可轮转的画册。

**结构分层（从底到顶）**

```
① 视频背景层   全屏 <video>，海洋 / 阳光 / 鱼，循环播放，作氛围底
② 暗化遮罩层   半透明深色渐变,压住视频对比度,保证上层文字可读
③ 内容层       标题「AI 无限」标语 + 毛玻璃画册轮播(模块入口) + 菜单推荐
```

**毛玻璃画册轮播（模块切换器）**
- 每个模块 = 一张毛玻璃卡片（`backdrop-filter: blur()` + 半透明白边 + 圆角 + 阴影），卡面放模块图标/名称/一句话简介。
- 默认**自动轮转**（如 4~5 秒切一张），鼠标悬停暂停；支持左右手动切换与底部指示点。
- 点击卡片 → `router.push` 进入该模块（`/cars`、`/menu`、`/tools`）。
- 复用现有视觉变量：项目 `App.vue` 顶栏已用 `backdrop-filter: blur(12px)`，画册沿用同一套毛玻璃/发光风格，保持一致。

**菜单推荐位**
- 首屏在画册下方（或卡片内）展示「菜单推荐」。菜单模块未上线前，先用**占位/静态示例数据**，模块上线后再接真实接口。

**视频与移动端注意事项（实现前需落实）**
1. **素材来源与授权**：海洋/鱼视频需用可商用免费素材（如 Pexels/Coverr）或自备，避免版权风险；单文件体积控制（建议压到 2~5MB、720p 循环片段）以免拖慢首屏。
2. **移动端自动播放**：`<video>` 必须同时带 `muted` `autoplay` `loop` `playsinline`，否则 iOS/安卓不自动播；再配 `poster` 首帧图兜底。
3. **弱网/低端设备降级**：低带宽或 `prefers-reduced-motion` 时可只显示 `poster` 静图，不强拉视频，避免白屏和卡顿。
4. **性能**：视频懒加载、`preload="metadata"`；毛玻璃 `blur` 在低端机有性能成本，卡片数量克制。
