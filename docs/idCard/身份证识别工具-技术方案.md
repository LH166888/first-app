# 身份证识别工具 · 技术方案

> 在「车榜」现有前后端分离架构上，新增一个**身份证识别工具页**：用户上传身份证照片（可能歪斜/带背景），后端调用百度 OCR 完成**自动摆正 + 去背景裁剪 + 文字识别**，前端可**预览、下载摆正后的图片**并展示识别出的姓名、身份证号等字段。
>
> 创建于 2026-09-14。本文件为落地前的技术设计，实现时如与现状有出入会回填。

---

## 一、需求与范围

### 1.1 目标
- 入口：顶部导航栏新增「工具 ▾」下拉，内含「身份证识别」，点击进入独立页面 `/tools/idcard`。
- 用户上传一张身份证照片 → 后端识别 → 返回：
  1. **摆正 + 裁剪后的身份证整图**（供预览与下载）；
  2. **结构化字段**（正面：姓名、性别、民族、出生、住址、公民身份号码；背面：签发机关、有效期）；
  3. **风控/质量提示**（复印件、翻拍、PS、模糊等）。

### 1.2 关键产品决策（已确认）
| 决策项 | 结论 | 理由 |
|--------|------|------|
| 是否限登录 | **必须登录**（Sanctum 中间件保护） | 防止接口被白嫖刷光百度免费额度；身份证属敏感信息，需可追溯的调用主体 |
| 摆正图存储 | **不落盘**，base64 直接回前端 | Render 容器无状态、重启即丢；身份证敏感，零留存最合规 |
| 文字是否落库 | **不落库**，仅前端展示 | 同上，最小化敏感信息留存 |
| 移动端菜单 | 桌面/窄屏**都用「工具 ▾」下拉** | 交互统一 |

### 1.3 非目标（本期不做）
- 不做识别历史记录、不做批量上传、不做人脸比对/活体核验。
- 不引入对象存储（与「不落盘」决策一致）。

## 二、技术选型与现有架构结合

沿用现有技术栈，不引入新框架：

| 层 | 现有 | 本需求新增 |
|----|------|-----------|
| 前端 | Vue 3 + Vite + vue-router(hash) | 新增 1 个视图 `IdCardToolView.vue`、1 条路由、顶栏「工具」下拉、1 个 API 封装 `api/idcard.js` |
| 后端 | Laravel 12（PHP 8.2）只做 API | 新增 `BaiduOcrService`、`IdCardController`、1 条受保护路由、`config/services.php` 增配 |
| HTTP 客户端 | vendor 已含 **Guzzle** | 直接用 Laravel `Http` 门面（内部即 Guzzle），无需装包 |
| 第三方 | — | 百度智能云「文字识别 OCR - 身份证识别」 |

> **为什么用 `Http` 门面而不是裸 Guzzle**：Laravel `Http` 是对 Guzzle 的官方封装，写法更简洁、便于超时/重试/Fake 测试，符合 Laravel 12 惯例。

## 三、整体流程

```
用户浏览器 (IdCardToolView.vue)
   │  ① 选择身份证图片 + side(front/back)，multipart 上传
   │     带 Authorization: Bearer <token>
   ▼
Laravel 后端  POST /api/tools/idcard/recognize   [auth:sanctum]
   │  ② 校验：登录态 / 文件类型(jpg,png) / 大小(≤4MB)
   │  ③ 取 access_token（Cache 缓存，命中直接用）
   │  ④ 图片 base64 → 调百度身份证识别接口
   │        detect_card / detect_photo / detect_risk / detect_quality / detect_direction
   ▼
百度 OCR
   │  ⑤ 返回：words_result + card_image(摆正裁剪图,base64) + risk/quality + image_status
   ▼
Laravel 后端
   │  ⑥ 解析：image_status 兜底 → 提字段 → 本地校验身份证号(校验位)
   │     card_image 原样透传（不落盘）
   ▼
前端
   │  ⑦ 预览摆正图 + 展示字段 + 风险提示
   │  ⑧ 点击「下载」：base64 → Blob → a[download] 保存为 jpg
```

### 4.3 `BaiduOcrService`（核心封装）

职责：① 取并缓存 `access_token`；② 调身份证识别接口；③ 解析成前端友好结构。风格对齐现有控制器（数组校验、`response()->json`、中文注释）。

```php
<?php

namespace App\Services;

use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Facades\Http;
use RuntimeException;

class BaiduOcrService
{
    private const TOKEN_URL  = 'https://aip.baidubce.com/oauth/2.0/token';
    private const IDCARD_URL = 'https://aip.baidubce.com/rest/2.0/ocr/v1/idcard';

    /**
     * 获取 access_token（缓存 29 天；百度有效期约 30 天）。
     */
    public function accessToken(): string
    {
        return Cache::remember('baidu_ocr_token', now()->addDays(29), function () {
            $resp = Http::asForm()->timeout(10)->post(self::TOKEN_URL, [
                'grant_type'    => 'client_credentials',
                'client_id'     => config('services.baidu_ocr.api_key'),
                'client_secret' => config('services.baidu_ocr.secret_key'),
            ])->json();

            if (empty($resp['access_token'])) {
                throw new RuntimeException('百度 access_token 获取失败');
            }
            return $resp['access_token'];
        });
    }

    /**
     * 身份证识别。
     *
     * @param  string $imageBinary  原始图片二进制
     * @param  string $side         front | back
     * @return array  百度原始返回（已确保无 error_code）
     */
    public function recognizeIdCard(string $imageBinary, string $side = 'front'): array
    {
        $token = $this->accessToken();

        $resp = Http::asForm()
            ->timeout(20) // 跨境调用，超时给足，见第八节风险说明
            ->post(self::IDCARD_URL . '?access_token=' . $token, [
                'image'            => base64_encode($imageBinary),
                'id_card_side'     => $side,
                'detect_card'      => 'true',   // 关键：返回摆正裁剪整图 card_image
                'detect_photo'     => 'true',   // 返回头像切图 photo（可选展示）
                'detect_direction' => 'true',
                'detect_risk'      => 'true',
                'detect_quality'   => 'true',
            ])->json();

        // token 失效（110/111）：清缓存后重试一次
        if (in_array($resp['error_code'] ?? null, [110, 111], true)) {
            Cache::forget('baidu_ocr_token');
            return $this->recognizeIdCard($imageBinary, $side); // 单次重试
        }

        if (isset($resp['error_code'])) {
            throw new RuntimeException("百度接口错误[{$resp['error_code']}]: " . ($resp['error_msg'] ?? ''));
        }

        return $resp;
    }

    /**
     * 把百度返回整理成前端契约结构。
     */
    public function normalize(array $resp): array
    {
        $status = $resp['image_status'] ?? 'unknown';

        $w = $resp['words_result'] ?? [];
        $get = fn (string $k) => $w[$k]['words'] ?? '';

        $idno = $get('公民身份号码');

        return [
            'image_status' => $status,
            'fields' => [
                'name'    => $get('姓名'),
                'sex'     => $get('性别'),
                'nation'  => $get('民族'),
                'birth'   => $get('出生'),
                'address' => $get('住址'),
                'idno'    => $idno,
                // 背面字段（side=back 时有值）
                'authority'   => $get('签发机关'),
                'valid_date'  => $get('失效日期'),
                'issue_date'  => $get('签发日期'),
                'idno_valid'  => $idno ? $this->validateIdNo($idno) : null,
            ],
            // 摆正裁剪整图（base64，无编码头）→ 拼成 data URI 方便前端直接用
            'card_image' => !empty($resp['card_image'])
                ? 'data:image/jpeg;base64,' . $resp['card_image'] : null,
            'photo' => !empty($resp['photo'])
                ? 'data:image/jpeg;base64,' . $resp['photo'] : null,
            'risk' => [
                'risk_type'    => $resp['risk_type'] ?? null,
                'card_quality' => $resp['card_quality'] ?? null,
            ],
        ];
    }

    /**
     * 身份证号本地校验（GB 11643 校验位）。
     */
    public function validateIdNo(string $id): bool
    {
        if (!preg_match('/^\d{17}[\dXx]$/', $id)) {
            return false;
        }
        $w = [7,9,10,5,8,4,2,1,6,3,7,9,10,5,8,4,2];
        $codes = ['1','0','X','9','8','7','6','5','4','3','2'];
        $sum = 0;
        for ($i = 0; $i < 17; $i++) {
            $sum += (int) $id[$i] * $w[$i];
        }
        return strtoupper($id[17]) === $codes[$sum % 11];
    }
}
```

### 4.4 `IdCardController`

```php
<?php

namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use App\Services\BaiduOcrService;
use Illuminate\Http\Request;

class IdCardController extends Controller
{
    public function __construct(private BaiduOcrService $ocr) {}

    /**
     * 身份证识别。multipart: image(文件), side(front|back)。
     * 返回摆正裁剪图(base64) + 结构化字段 + 风险提示。图片与文字均不落盘、不落库。
     */
    public function recognize(Request $request)
    {
        $data = $request->validate([
            'image' => ['required', 'image', 'mimes:jpg,jpeg,png', 'max:4096'], // ≤4MB
            'side'  => ['nullable', 'in:front,back'],
        ]);

        $side   = $data['side'] ?? 'front';
        $binary = file_get_contents($request->file('image')->getRealPath());

        try {
            $resp   = $this->ocr->recognizeIdCard($binary, $side);
            $result = $this->ocr->normalize($resp);
        } catch (\Throwable $e) {
            // 不把身份证明文写日志；只记类型与消息
            report($e);
            return response()->json(['code' => 5001, 'msg' => '识别服务暂时不可用，请稍后重试'], 502);
        }

        // 图片状态兜底提示
        $tips = [
            'reversed_side' => '正反面拍反了，请上传对应面',
            'non_idcard'    => '未检测到身份证，请上传清晰的身份证照片',
            'blurred'       => '图片模糊，请重拍',
            'over_exposure' => '图片过曝，请重拍',
        ];
        if (isset($tips[$result['image_status']])) {
            return response()->json(['code' => 4001, 'msg' => $tips[$result['image_status']]], 422);
        }

        return response()->json(['code' => 0, 'msg' => 'ok', 'data' => $result]);
    }
}
```

### 4.6 接口契约（前后端约定）

**请求** `POST /api/tools/idcard/recognize`（`multipart/form-data`，需登录）
| 字段 | 必填 | 说明 |
|------|------|------|
| image | 是 | 图片文件，jpg/jpeg/png，≤4MB |
| side | 否 | front（默认）/ back |

**成功响应** `200`
```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "image_status": "normal",
    "fields": {
      "name": "张三", "sex": "男", "nation": "汉",
      "birth": "19900101", "address": "…", "idno": "1101…1234",
      "idno_valid": true,
      "authority": "", "valid_date": "", "issue_date": ""
    },
    "card_image": "data:image/jpeg;base64,/9j/…",
    "photo": "data:image/jpeg;base64,/9j/…",
    "risk": { "risk_type": "normal", "card_quality": { } }
  }
}
```

**业务错误**
| HTTP | code | 场景 |
|------|------|------|
| 422 | 4001 | 图片状态异常（拍反/非身份证/模糊/过曝） |
| 422 | — | 表单校验失败（Laravel 默认 errors 结构：文件缺失/超限/类型错） |
| 401 | — | 未登录 / token 失效（前端 client.js 已统一处理，清登录态） |
| 502 | 5001 | 百度服务异常（含跨境超时、额度用尽等，见下） |

> 额度类错误（error_code 17 当日额度用尽、18 QPS 超限）在 Service 层抛出、Controller 统一归 5001，前端提示「识别服务暂时不可用」。后续如需细分可再拆 code。

## 六、安全与合规（身份证＝敏感个人信息，必须做）

1. **接口鉴权**：`auth:sanctum` 保护，未登录 401。防止免费额度被刷。
2. **全链路 HTTPS**：前端 Vercel、后端 Render 均已强制 HTTPS。
3. **零留存**：图片与识别文字**均不落盘、不落库**，仅在单次响应里返回，用完即弃（契合 Render 无状态容器）。
4. **日志脱敏**：异常只 `report($e)` 记类型/消息，**不打印身份证号、姓名、图片内容**。
5. **密钥管理**：百度 API/Secret Key 走 `.env` / Render 环境变量，不进 git。
6. **前端告知**：页面注明「图片仅用于本次识别，不会被服务器保存」，取得用户知情（符合《个人信息保护法》最小必要原则）。
7. **可选加固（后续）**：对该接口加按用户/IP 的 RateLimiter，进一步防滥用。

## 七、百度额度与计费（运营提示）
- 个人实名认证：身份证识别 **1000 次/月免费**，需在控制台「免费资源」页手动领取；成功与失败调用都消耗额度。
- 超出后按次/资源包计费。因已限登录 + 零留存，正常个人使用量在免费额度内。
- `detect_direction` 仅返回方向值，**摆正整图来自 `detect_card`**，二者别混。

---

## 八、⚠️ 跨境延迟风险与预案（重要）

**现状风险**：后端在 Render **新加坡**，百度 OCR 在**中国大陆**，`后端 → 百度` 为跨境调用，存在**较高延迟与偶发超时**；叠加国内用户 `→ 新加坡后端` 本身已有约 0.1–0.25s 跨境延迟，端到端可能偏慢。

**本期策略**：先按现状实现跑通，实测真实延迟与成功率。代码已做的缓解：
- Service 调百度 `timeout(20s)`、前端 `timeout(30s)`，避免过早失败；
- token 缓存，省掉每次取 token 的一次跨境往返；
- token 失效自动重试一次。

**后续可选优化（实测不达标再上）**：
1. 对超时/限流（error_code 18）做**指数退避重试**；
2. 把「调百度」这一步迁到**国内节点**（如后续阶段 C 的腾讯云 CloudBase 函数）做中转，缩短到百度的距离；
3. 若整体后端迁国内（架构文档阶段 C/D），此问题自然消解。

> 结论：**不阻塞本期开发**，作为已知风险记录，实测后决定是否优化。
